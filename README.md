# Big If True

Fragility of the manipulable-voter model and the implications for politics and
social science. Working paper by Andrew Gelman, John Bullock, and Gaurav Sood.
The current public draft is
[on Andrew Gelman's site](https://sites.stat.columbia.edu/gelman/research/unpublished/manipulable.pdf).

The manuscript is `ms/main.tex`, with references in `ms/references.bib`. Build
the PDF with `make paper`, which needs a TeX distribution with `latexmk`. CI
builds it on every push and pull request and attaches `main.pdf` to the run.
